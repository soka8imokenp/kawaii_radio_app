# Kawaii Radio KR-01

Мобильное радио Kawaii.uz в стиле тактильного карманного синтезатора (Teenage Engineering × Braun): меловой матовый пластик, выдавленные и вдавленные клавиши, утопленные лотки, изумрудный LED и красная метка тюнера.

## Стек

Нативное приложение, без WebView:

- **Kotlin + Compose Multiplatform**: весь интерфейс рисуется напрямую на GPU. Экраны, дизайн-система и логика лежат в общем модуле, поэтому позже можно собрать и iOS-версию.
- **Media3 / ExoPlayer**: фоновое воспроизведение, экран блокировки, кнопки наушников и Bluetooth, дисковый кэш песен (400 МБ).
- **Coil 3**: обложки. **kotlinx.serialization**: плейлист и релизы.
- APK весит около 3.4 МБ: вся музыка приходит из облака.

```
native/
  shared/       всё общее: экраны (ui/), дизайн-система (ui/kit, ui/theme), плейлист, тексты, обновления
                платформенные вещи спрятаны за интерфейсом Platform (Platform.kt)
  androidApp/   Android: Media3-плеер (audio/), волновая форма, щелчки клавиш, установщик обновлений
cloud/          Cloudflare Worker + R2: playlist.json, mp3 и обложки
```

## Возможности

- Тёмная верхняя панель: вкладки J-Pop / Anime OST / Saqlangan, 3D-карусель обложек со свайпом, подсветка в цвет обложки, текст песни. Панель тянется вниз и показывает весь текст.
- LCD с настоящей волновой формой трека. Читается выборочно (около 100 мс на каждую полоску) и кэшируется на диске, так что даже на слабом телефоне не тормозит. Перемотка свайпом по волне.
- Синхронный текст песни пиксельным шрифтом, переключение UZ / JP.
- Колесо-тюнер со щелчками на каждом делении, тап по краям переключает на соседнюю станцию.
- Play/Pause, лайк, «Tavsif» (описание песни), «Saqlash» (сохранение для офлайна, функция Kawaii Pass).
- Нижняя навигация: Asosiy, Sevimlilar, Profil.
- Подписка пока задаётся флагом `kr01-premium = 1` в настройках приложения. Это временно, до подключения бэкенда Kawaii Pass.

## Сборка

Нужны JDK 21 и Android SDK (platform 37).

```bash
cd native
./gradlew :androidApp:assembleDebug     # или assembleRelease (R8, подписан ключом kr01)
```

## Облако

- `cloud/`: Cloudflare Worker + R2. Приложение при запуске и при возврате из фона берёт `playlist.json` и запоминает его, чтобы следующий запуск был мгновенным даже без интернета.
- Адрес воркера задан в `native/shared/src/commonMain/kotlin/uz/kawaii/radio/data/Catalog.kt` (`CLOUD_URL`).
- Доступ на запись: `cloud/.secrets` (не коммитится). Токен должен совпадать с секретом `UPLOAD_TOKEN` у воркера в Cloudflare.
- Добавить папку песен: `node cloud/import.mjs <папка>`. Правила для агента: `cloud/AGENT.md`.

## Обновления

- Каждый push в `main` запускает GitHub Actions: собирается подписанный APK и публикуется релиз `v1.0.<номер сборки>` с файлом `kawaii-radio.apk`. Текст коммита становится списком изменений, поэтому он пишется на узбекском.
- Приложение при запуске проверяет последний релиз и показывает панель «Yangi versiya chiqdi!»: загрузка с прогрессом, затем установщик Android.
- Все сборки подписаны одним ключом `native/androidApp/kr01-release.p12`, поэтому новая версия ставится поверх старой, в том числе поверх старой Capacitor-версии.
