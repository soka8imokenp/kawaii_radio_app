# Kawaii Radio KR-01

Мобильное приложение-радио Kawaii.uz в стиле тактильного карманного синтезатора (Teenage Engineering × Braun): меловой матовый пластик, выдавленные и вдавленные клавиши, утопленные лотки, изумрудный LED и красная метка тюнера.
Референс: Neumorphic AI Music Generator App (Dribbble).

## Стек
- **Vite + React 19 + TypeScript**: мгновенный dev-сервер и сборка
- **Tailwind CSS v4** + собственные токены материала (`src/index.css`: `.raised`, `.well`, `.bezel`, `.lcd`)
- **Motion**: пружинные нажатия кнопок, шторки, стрелка шкалы, анимации LCD
- **Capacitor 8**: Android-приложение, хаптика (`@capacitor/haptics`), статус-бар, фоновое воспроизведение и управление с экрана блокировки (`@jofr/capacitor-media-session`)

## Возможности
- Экран как в референсе: тёмная верхняя панель (переключатель J-Pop / Anime OST, карусель обложек со свайпом, текст песни) и светлый «железный» корпус снизу
- LCD с настоящей волновой формой трека (декодируется из mp3): плейхед по центру, перемотка свайпом по волне, индикаторы LYRICS / ON AIR, помехи при настройке
- Синхронный текст песни пиксельным шрифтом (DotGothic16) ; язык UZ / JP переключается индикаторами в нижней строке LCD
- Колесо-тюнер: свайп со щелчками и вибрацией на каждом делении, тап по краям для prev/next внутри выбранной вкладки
- Кнопки: Play/Pause, лайк, «Tavsif» (описание песни), «Saqlash» (сохранить внутри приложения, функция Kawaii Pass)
- Вкладка «Saqlangan»: сохранённые песни, аудио кэшируется (Cache Storage) для офлайна
- Подписка: флаг `localStorage.kr01-premium = '1'` (временный, до подключения бэкенда Kawaii Pass)
- Нижняя навигация: Asosiy (радио), Sevimlilar (лайкнутые песни), Profil (статус Kawaii Pass, язык текста, вход на kawaii.uz)
- Состояние (трек, лайки) сохраняется в localStorage

## Команды
```bash
pnpm install
pnpm dev            # http://localhost:5199 (открывать в мобильном вьюпорте)
pnpm build
pnpm cap:sync       # сборка и синхронизация с android/
pnpm android        # открыть в Android Studio
```
## Облако (свои треки без пересборки)
- `cloud/`: Cloudflare Worker + R2. Хранит mp3, обложки и `playlist.json`; приложение подтягивает его при запуске и при возврате из фона и добавляет эти треки после встроенных.
- Первый запуск: `cd cloud && npm install && npx wrangler login && ./setup.sh`. Скрипт создаст бакет, задеплоит Worker, сгенерирует токен (`cloud/.secrets`, не коммитить) и пропишет адрес в `.env` (`VITE_CLOUD_URL`).
- Треки добавляет Telegram-агент по инструкции `cloud/AGENT.md`.
- Локально: `cd cloud && npx wrangler dev` + `.env.local` с `VITE_CLOUD_URL=http://127.0.0.1:8787`.

## Обновления
- Каждый push в `main` → GitHub Actions собирает подписанный APK и публикует релиз `v1.0.<номер сборки>` с файлом `kawaii-radio.apk` (текст коммита = список изменений).
- Приложение при запуске проверяет последний релиз и показывает панель «Yangi versiya chiqdi!»: загрузка с прогрессом → установщик Android.
- Все сборки подписаны одним ключом `android/app/kr01-release.p12` (создан `scripts/make-keystore.cjs`), поэтому новая версия ставится поверх старой с сохранением данных. Для Google Play нужен отдельный приватный ключ.
- Превью панели в браузере: `http://localhost:5199/?update-demo`.

Треки, обложки и тексты взяты из `radio_kawaiia_v2`.
